# Station Project 1: Mad Libs Game

A Python-based interactive console game built for TUMO Labs. The program asks players for various words (nouns, verbs, adjectives, etc.) without revealing the context, then generates a complete Mad Libs story.

---

## Features & Requirements

* **Multiple Templates**: Select from three classic stories (Hospital, Camping Trip, or Enchanted Castle) or pick a random story.
* **Core Concepts Used**:
  * **Functions**: Modular game logic (`play_mad_libs()`).
  * **Conditionals**: Handles template choices and user inputs.
  * **Loops**: Dynamically loops through prompt lists and validates input.
  * **Arrays/Lists**: Stores template strings, prompt lists, and user answers.
  * **Strings**: Formats prompt strings dynamically.
  * **Random Library**: Selects random templates upon user request.
